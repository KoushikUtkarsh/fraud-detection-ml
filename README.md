\# Credit Card Fraud Detection using Machine Learning



This project compares multiple machine learning models for credit card fraud detection using an imbalanced dataset.



\## Models Used

\- Logistic Regression

\- KNN

\- Random Forest

\- SVM

\- Gradient Boosting

\- Hybrid Soft-Voting Ensemble



\## Results



| Model | ROC-AUC |

|---|---|

| SVM | 0.9808 |

| Ensemble | 0.9791 |

| Gradient Boosting | 0.9778 |

| Random Forest | 0.9746 |

| Logistic Regression | 0.9679 |

| KNN | 0.9525 |
